# Правила работы с кодом

## Границы изменений

- Перед правками изучите ближайшие `AGENTS.md`, состояние Git, затронутый код, его вызывающие стороны и существующие тесты.
- Сохраняйте чужие незакоммиченные изменения. Не переписывайте историю и не удаляйте файлы вне согласованной задачи.
- Делайте узкие, обратимые изменения в рамках существующих модулей и стиля проекта. Новые зависимости и изменения публичных контрактов обосновывайте.
- Не добавляйте в исходники, документацию, тесты и артефакты реальные ссылки подписок, пользовательские профили, приватные адреса серверов, токены, ключи, платёжные данные или неочищенные логи.
- Не изменяйте внешние системы, настройки репозитория и рабочую инфраструктуру без явного разрешения на конкретную задачу.

## Код и проверки

- Для изменений поведения добавляйте регрессионные тесты; перед отправкой запускайте подходящие проверки из `CONTRIBUTING.md` и перечисляйте фактические результаты.
- Проверяйте форматирование и анализатор для изменённых языков. Не представляйте сборку или статический анализ как доказательство работы на устройстве или в production.
- Сохраняйте совместимость поддерживаемых ОС и ранее выпущенных форматов; миграции и изменения протокола покрывайте тестами.
- Комментарии в коде пишите кратко на английском и добавляйте только для объяснения неочевидного решения.
- Обновляйте пользовательскую документацию и журнал изменений вместе с заметным пользовательским поведением.

## Git и взаимодействие

- Предпочитайте отдельную ветку для одной задачи и pull request с кратким описанием цели, платформ, рисков и проверок.
- Не включайте в коммит посторонний WIP, локальные настройки, сгенерированные сборки и файлы секретов.
- Сохраняйте существующие уведомления об авторских правах и лицензиях; проверяйте лицензию новых зависимостей и материалов.
- Для публичных Issue и pull request используйте только тестовые данные. Сообщения об уязвимостях направляйте приватно по `SECURITY.md`.
- Не выполняйте релиз, публикацию, deployment или изменение production в рамках обычной разработки и проверки.
