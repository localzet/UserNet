# История изменений UserNet

Этот файл начинается с первой отдельной публикации исходников UserNet. Для старых версий см. заметки соответствующих релизов после их публикации в этом репозитории.

## 0.5.12 — первая отдельная версия исходного кода

- Добавлены аккаунт и управление подпиской Aura Network.
- Добавлены интерфейс выбора сервера, диагностика соединения и дополнительные сценарии доступа.
- Обновлены бренд, значки и страница загрузки UserNet.
- Добавлены проверка обновлений и индикатор прогресса загрузки.
- Подготовлены формы Issues и правила контрибьютинга.

Это список возможностей исходного снимка кода, а не заявление о доступности релизных пакетов для каждой платформы. Фактические файлы и поддерживаемые версии публикуются на странице загрузки и в релизах.
