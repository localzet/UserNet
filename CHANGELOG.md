# История изменений UserNet

Этот файл начинается с первой отдельной публикации исходников UserNet. Для старых версий см. заметки соответствующих релизов после их публикации в этом репозитории.

## 0.5.13 — стабильность подключения

- Android: резервный доступ через звонки автоматически восстанавливает соединение после возврата сети и не перезапускает уже работающий канал без необходимости.
- Android: сетевой наблюдатель и DNS-разрешение остаются активны, пока работает резервный relay после закрытия окна приложения.
- Android: Core предварительно загружается в фоне, а Geo-базы копируются без блокировки интерфейса и становятся видимыми только после полной записи.
- Core: одинаковые имена узлов в подписке и proxy provider разрешаются стабильно, без случайного выбора при пересборке кэша.
- Core: YAML alias с REALITY `short-id` сохраняют исходный тип общих значений; большие списки правил остаются доступными после сериализации.
- Core: настройки, унаследованные через YAML merge, учитываются при сборке профиля.
- Core: импорт и экспорт ссылок сохраняет спецсимволы в паролях Hysteria2 и SOCKS.
- Windows: обновлённые MMDB и ASN устанавливаются при следующем старте Core, не закрывая базу во время активных lookup.

## Неопубликованные изменения

- Улучшен автоматический выпуск одной и той же проверенной сборки в OTA и GitHub Releases.

## 0.5.12 — первая отдельная версия исходного кода

- Добавлены аккаунт и управление подпиской Aura Network.
- Добавлены интерфейс выбора сервера, диагностика соединения и дополнительные сценарии доступа.
- Обновлены бренд, значки и страница загрузки UserNet.
- Добавлены проверка обновлений и индикатор прогресса загрузки.
- Подготовлены формы Issues и правила контрибьютинга.

Это список возможностей исходного снимка кода, а не заявление о доступности релизных пакетов для каждой платформы. Фактические файлы и поддерживаемые версии публикуются на странице загрузки и в релизах.
